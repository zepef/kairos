## 1. Principes fondateurs
1. **Voix d'abord** — l'interaction normale est parlée ; l'écran est un retour ponctuel.
2. **Écran minimal** — rien par défaut ; le contenu n'apparaît que sur commande système explicite, et se masque.
3. **On-device & offline** — STT, Gemma 4 et SQLite tournent sur l'appareil, sans réseau.
4. **Intelligence remplaçable** — le LLM ne fait que *traduire langage → action structurée* ; il n'écrit jamais en base. Logique métier déterministe, testable sans LLM.
5. **Tout est réversible** — aucune action destructrice sans recours (archiver ≠ supprimer ; un statut se ré-applique).

## 2. Entités
**Tâche (`task`)** = l'unité atomique (seule chose créée ; dossiers/vues en dérivent). Attributs :
`title` · `due` (tel que dit) · `due_iso` (résolu, pour le filtrage temporel) · `priority` 0-3 → **URGENT** · `category` (**QUOI**) · `subcategory` · `person` (**QUI**) · `place` (**OÙ**) · `status` (**ÉTAT**) · `created_at`/`completed_at`.

- **Dossier (`category`)** niveau 1, émergent (créé à la volée, jamais affiché si vide) : *thématique* (Santé, Courses, **Contact** = appeler qqn, Travail, Rendez-vous, Finances, Famille, Divers) ou *projet* (le dossier = le nom du projet).
- **Sous-dossier (`subcategory`)** niveau 2 optionnel → hiérarchie **Dossier › Sous-dossier › Tâche**.
- **Portée temporelle (`scope`)** — fenêtre de lecture : `all`/`hours`/`day`/`week`/`month`/**`overdue`**/**`reminder`** (à venir ≤24h + en retard).

## 3. Cycle de vie des statuts
```
[todo] ──pending──► [pending] ──reprendre──► [todo] ──faire──► [done]
   │  ◄─────────────── reporter ──────────────┘
   └──────── archiver ────────► [archived] ◄──── done
[postponed] ◄── reporter ── (todo|pending)
```
| Statut | Sens | Dans les listes « ouvertes » ? |
|---|---|---|
| `todo` | à faire | oui |
| `pending` | en attente | oui (badge) |
| `postponed` | à reporter | oui (badge) |
| `done` | accomplie | non |
| `archived` | archivée (rangée ≠ supprimée) | non |

→ liste « ouverte » = tout sauf `done`/`archived`.

## 4. Les 3 familles de commandes (`tool`)

**4.1 Données (CRUD)**
- `createTask` — titre + échéance + dossier/sous-dossier + priorité + personne + lieu (déduits).
- `updateTask` — modifie des attributs partiels (`changes`) : replanifier, déplacer, renommer, réaffecter, reprioriser.
- `setStatus` — done / pending / postponed / archived / todo.
- `deleteTask` — supprime UNE tâche (réversible).
- `deleteTasks` — supprime PLUSIEURS d'un coup (par numéros, ou toute une journée via `dayISO`) — réversible en bloc.
- `undo` (« annule ») — défait la dernière mutation (y compris un groupe).

*Référence & désambiguïsation* : tout affiché est **numéroté** ; le numéro est la référence sûre. Sinon mots-clés du titre → 0 (le dit) / 1 (agit) / plusieurs (affiche candidats numérotés, « laquelle ? »).

**4.2 Système / vue** (n'altèrent rien)
- `showTasks(...)` — seule façon d'afficher des tâches (groupées par dossier › sous-dossier), masquable par ✕. **6 dimensions composables** (§5).
- `showCalendar` — calendrier graphique paysage (jour/semaine/mois/année).
- `zoomCalendar` — zoom relatif du calendrier ouvert (in = plus de détail, out = plus large).

**4.3 Inconnu**
- `unknown` — rien ne correspond → l'app le dit, ne devine pas.

## 5. Les 6 dimensions de filtrage (composables sur `showTasks`)
| Dimension | Question | Paramètre | Valeurs |
|---|---|---|---|
| **QUOI** | quel dossier/projet | `category` | nom ou `null` |
| **QUAND** | quelle fenêtre | `scope` | all/hours/day/week/month/overdue/reminder |
| **QUI** | quelle personne | `person` | nom ou `null` |
| **OÙ** | quel lieu | `place` | lieu ou `null` |
| **ÉTAT** | quel statut | `status` | pending/postponed/done/archived/todo ou `null` |
| **URGENT** | priorité haute | `urgent` | true/false (priorité ≥ 2) |

Sans mention temporelle → `scope:all`. Sans `status` → liste « ouverte ».

## 6. Le pont langage → action
```
Voix ─STT on-device─► texte ─► Gemma 4 (+date) ─► JSON {tool, params}
   ─► dispatch (déterministe) ─► DB ou Vue ─► confirmation TTS
```
Gemma = **traducteur d'ontologie** : formulation libre → (intention, entités, attributs) ; résout aussi les références floues et les dates relatives.
